## Technologies

Each website uses semantic HTML5 and a separate CSS3 stylesheet. Layouts use CSS Grid, Flexbox, responsive media queries, and anchor navigation. No build tools or server are required.

## Run a website

Open the `index.html` file inside the chosen case-study folder in a modern web browser. The styles load from the adjacent `style.css`. An internet connection is needed for the remote photographs and movie poster images referenced by the pages; the layouts and text are otherwise local.

- Tourism: `case-17-tourism/index.html`
- Movie reviews: `case-22-movie-review/index.html`
- Gaming and esports: `case-23-gaming-esports/index.html`
